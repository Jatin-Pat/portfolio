## Full Stack Development

### [Cranki: Task Management App](https://github.com/vladarama/cranki)
**Tools:** `React`, `Vite`, `Spring Boot`, `Gradle`, `REST API`  
📜 **Project Description:**  
Cranki is a modern task manager with support for priority-based task creation, status tracking, filtering, and an intuitive UI. The frontend is built with React and Vite, and the backend uses Spring Boot with RESTful services.

## Systems Programming

### [Mini-OS](https://github.com/Jatin-Pat/mini-os)
**Tools:** `C`, `Make`, `POSIX`  
📜 **Project Description:**  
A simulated OS shell built from scratch. Supports command parsing, script execution, process scheduling (FCFS, SJF, RR, AGING), and demand paging with LRU replacement. Implements multi-process handling and memory isolation.

---

## Networking

### [DNS Client](https://github.com/Jatin-Pat/DNS_Client)
**Tools:** `Python`, `Sockets`  
📜 **Project Description:**  
Implements a DNS client that performs `A`, `NS`, and `MX` record queries using UDP sockets. Includes retransmission logic, detailed response parsing, and command-line interface with support for flags like timeout, retries, and port override.

---

## Signal & Image Processing

### [Discrete Fourier Transform Tool](https://github.com/Jatin-Pat/fft)
**Tools:** `Python`, `NumPy`, `Matplotlib`, `OpenCV`  
📜 **Project Description:**  
A toolkit for performing 1D/2D DFTs and FFTs on images. Includes visualizations, denoising, and image compression via frequency filtering. Also supports runtime benchmarking of naive vs. FFT algorithms and IFFT validation.
